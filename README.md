# 钢铁对决 - 像素风机甲对战游戏

## 游戏介绍

**钢铁对决**是一款像素风格的机甲对战游戏，支持单人闯关和双人对战模式。

### 游戏特色

- 🎮 **8种独特机甲** - 每个角色都有专属技能和宠物
- ⚔️ **15个关卡** - 3章内容，难度递进
- 🌐 **P2P联机对战** - 基于 WebRTC 的实时对战，无需服务器中转
- 📱 **完美适配手机** - 支持触摸控制，横屏游玩

### 游戏模式

1. **关卡模式** - 挑战AI，解锁新内容
2. **本地联机** - 两台手机通过WiFi热点P2P对战

## 联机对战说明

### 纯手机热点联机（无需电脑）

1. 手机A开启WiFi热点（需有移动数据）
2. 手机B连接手机A的热点
3. 两台手机都访问游戏网址
4. 手机A：点"本地联机" → "创建房间" → 获得6位房间号
5. 手机B：点"本地联机" → "加入房间" → 输入房间号
6. 双方选角色 → 准备就绪 → 开始对战

### 技术原理

- 使用 **PeerJS** 库实现 WebRTC P2P 通信
- PeerJS 提供公共信令服务器，两台手机直接建立连接
- 输入同步：每帧发送按键状态，双方各自模拟

## 技术栈

- **联机**: WebRTC (PeerJS)
